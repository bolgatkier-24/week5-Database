# Database Indexing and Optimization

This assignment demonstrates basic database indexing, user management, privileges, and password management using MySQL.

## Questions Covered

* **Question 1:** Drops the `IdxPhone` index from the `customers` table.
* **Question 2:** Creates a user named `bob` restricted to the `localhost` host.
* **Question 3:** Grants the `INSERT` privilege to `bob` on the `salesDB` database.
* **Question 4:** Changes the password for the `bob` user.

## SQL Concepts Used

* `DROP INDEX`
* `CREATE USER`
* `GRANT`
* `ALTER USER`
* Database access control and user privileges
